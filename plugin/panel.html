    执行方式

    所有 CST 操作默认通过 cst-studio-suite MCP 驱动 CST Studio Suite 2026 执行。

    首次配置 本机环境

    填写本机的 CST 安装路径与 MCP 地址。这些值会写入任务指令，模型据此调用 MCP 与 CST； 只保存在本机浏览器（localStorage），不会写回源码文件。可在顶栏右上角的齿轮按钮中随时修改。
    CST 软件
    含 AMD64\、Library\ 的目录。
    CST MCP 服务
    需与 DSH 配置中的 serverName 一致；工具名前缀为 mcp__<服务名>__。
    MCP 生成的工程与 cst_runs/ 工作副本保存在此。证据目录由 MCP 自身的 .env（CST_MCP_EVIDENCE）决定，不在本页配置。
    本机自检（只校验配置填写，不代表 MCP 已连通）

    页面编辑器 自定义区块 0 个区块

    用 HTML 自由新增内容区块，按需扩展页面功能。区块保存在本机浏览器（localStorage），不会写回页面源码文件； 可用「导出 JSON」分享给他人导入。
    新增区块默认允许交互并执行脚本（每个区块默认勾选「允许执行脚本」）。若不需要交互，取消勾选即可；已运行过的脚本需要刷新本页面才会彻底停止，因为已经注册的计时器与事件监听不会因取消勾选而自动解除。
    示例参考：每轮仿真增益 / 效率统计

    新增区块时，数据回传通道填 stats，HTML 源码填 <div data-block-slot></div>，渲染方式选「内置表格渲染」。运行指令后，大模型每轮回传的仿真结果会写进该区块，按下表逐轮更新。

    可调用的页面接口 / 可复用的样式
    勾选「允许执行脚本」后，脚本运行在页面全局作用域，可直接调用已有函数：
    • toast(msg, type) —— 顶部提示，type 取 ok / warn / err
    • addLog(text) —— 写入左栏「操作日志」
    • readConfig() —— 读取当前表单配置对象
    • readSetup() —— 读取首次配置（CST 路径与 MCP 地址）
    • startSimulation() / pauseSimulation() / resumeSimulation() / cancelSimulation() —— 任务控制
    • dshRpc(method, payload) —— 直接调用 DSH 接口
    • 状态变量：runState、runId、bandState、actionLogs、FIXED_CONFIG
    直接复用页面设计令牌，自动跟随浅色 / 深色主题：
    • 现成类名：card、btn、pill、tag、mono、result-table
    • 颜色变量：var(--primary)、var(--text)、var(--text-sub)、var(--text-mute)、var(--ok)、var(--warn)、var(--err)、var(--surface)、var(--surface-2)、var(--border)、var(--mono)
