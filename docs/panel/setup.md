# 首次配置（页面内）

> **文档索引** › [配置面板](../README.md) › 首次配置（页面内）

页面顶栏右侧有 **齿轮图标** 按钮可随时重新打开该面板。

| 字段 | 对应环境变量 / 配置键 | 必填 |
| --- | --- | --- |
| CST 安装根目录 | `CST_INSTALL_ROOT` | ✅ |
| CST 可执行文件 | `CST_DESIGN_ENVIRONMENT_EXE` | ✅ |
| MCP 服务名 | `serverName`（DSH 配置中） | ✅ |
| MCP 传输方式 | `transport`：`stdio` 或 `http` | ✅ |
| MCP 启动命令 / 服务地址 | `command`（stdio）或 URL（http） | ✅ |
| MCP 启动参数 | `args`（stdio） | stdio 必填 |
| 工作区目录 | `CST_MCP_WORKSPACE` | 建议填写 |

> **证据目录不在本页配置。** 它由 MCP 自身的 `.env`（`CST_MCP_EVIDENCE`）决定，
> 见[安装与检测 CST MCP](../start/mcp.md)。本页只负责把模型需要知道的运行环境写进任务指令。
>
> **两个工作目录的占位符都只是示例，不是你的真实路径。** 左侧「任务工作目录 (cwd)」
> 留空时先由本页「工作区目录」回填；两者都空则**不向 DSH 传 cwd**，由 DSH 回落到它自己的
> 默认项目目录（启动 `dsh web` 时所在的目录）。**建议显式填写**——否则会话的工作目录
> 取决于你从哪个目录启动 DSH，工作副本也会落到那里。

## 保存与留存

配置只保存在浏览器 `localStorage`（键 `page-setup-v1`），**不写回页面源码文件**，
也不发送到任何第三方。

### 什么时候写盘

**只有点「保存配置」才写盘。** 输入框的 `input` 事件只用来即时刷新下方的自检清单，
**不落盘**。

这意味着一件容易踩的事：

> ⚠️ **填了但没点「保存配置」，改动不会留存，而且在关闭浮层时会被静默丢弃。**
> 无论用 ✕、「稍后再说」还是按 Esc 关闭，都是如此 —— 下次打开会显示**上次保存的值**。

### 保存之后能留多久

**一直留着，直到你主动改它。** 实测结论：

| 场景 | 结果 |
| --- | --- |
| 刷新页面 | ✅ 保留 |
| 关闭浏览器、下次重新打开 | ✅ 保留 |
| 打开浮层改了但**不保存**就关掉 | ❌ 改动被丢弃，仍用上次保存的值 |
| 点「恢复默认」 | ❌ 全部清空（有二次确认） |
| 换端口 / 换 host / 换协议 | ❌ 读不到（localStorage 按 origin 隔离） |
| 清除浏览器数据 / 无痕窗口 | ❌ 丢失 |

**保存过一次之后，首次配置浮层不会再自动弹出**（存档里 `configured: true`）。
之后要改配置，点顶栏的**齿轮图标**重新打开即可。

七个字段全部随保存一起留存：CST 安装根目录、CST 可执行文件、MCP 服务名、
MCP 传输方式、MCP 启动命令、MCP 启动参数、工作区目录。

> 与「页面编辑器」的区块不同，首次配置**没有独立的导出/导入按钮**。
> 搬迁地址（例如换端口）之前，请手动把这几项抄下来。

### 面板内的两层检测

**① 本机自检（7 项，即时）** —— 只校验「填了没、格式对不对」，**不代表 MCP 真的连通**：
同源可达 DSH、CST 路径为绝对路径、可执行文件以 `.exe` 结尾、MCP 服务名合法等。
每项有三种状态：**✓ 通过 / ✗ 填错 / ○ 尚未填写**（空值不会被显示为通过）。

**② 环境探测指令** —— 点按钮后会在 DSH 里**新建一个会话**并发送一条只做检测的指令，
要求模型实际调用 `cst_detect_tool`。这是唯一能真正验证 MCP 连通性的方式。

> 结果会**实时出现在右栏**（事件流与对话区）——会话事件由 `session/follow` 流推送过来，
> 契约见[与 DSH 的 RPC 契约](../dev/dsh-rpc.md)。发送成功时会弹一条带会话 ID 的提示；
> 同一个会话在 DSH 主界面里也能看到。

### 配置如何生效

- 生成任务指令时，会在最前面插入一节 `# 0. 运行环境（本机配置）`，包含 CST 路径、MCP 服务名与传输方式等；
- 若左栏「任务工作目录 (cwd)」为空，会自动用**工作区目录**填充；
- 指令中会明确要求：**若 MCP 工具不可用，必须直接报告不可用，不得改用其它途径伪造结果。**
