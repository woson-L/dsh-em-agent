# 页面编辑器

> **文档索引** › [页面编辑器](../README.md) › 页面编辑器

位于两栏下方，用于**不改动页面源码文件**的前提下扩展页面功能。

---

## 三件容易误会的事

| 你可能以为 | 实际行为 |
| --- | --- |
| 只能加一个区块 | **数量不限**。加多少个都行，每个独立配置、独立开关 |
| 刷新后就没了，需要手动「固定」 | **加完即存**。点「保存」的那一刻就写进 `localStorage`，刷新、关浏览器再打开都还在，**不需要任何额外选项** |
| 删除只能清空全部 | **可以单删**。每个区块的列表行和页面卡片上都有独立的「删除」 |

只有点 **「清空全部」** 才会一次性删光，且带二次确认。

## 界面

### 工具条

| 按钮 | 作用 |
| --- | --- |
| **新增区块**（主按钮） | 打开空白表单。**可以反复点**，每点一次准备一个新区块 |
| 导出 JSON | 把全部区块导出为 `.json`，用于分享或备份 |
| 导入 JSON | 选择 `.json` 文件导入；按 `id` 合并：同 id 覆盖，新 id 追加 |
| 清空全部 | 删除**所有**区块，带二次确认（确认框里会显示将要删除的数量）。不可撤销 |

### 区块列表

工具条下方**一行一个区块**，显示标题、放置区域、通道、累积标记与启用状态。

| 行内按钮 | 作用 |
| --- | --- |
| 上移 / 下移 | 调整同区域内顺序。**首行的「上移」与末行的「下移」自动置灰** |
| 测试 | 向该区块投递一份假数据，**不用真跑仿真**就能验证渲染。只有填了「数据回传」通道时才出现 |
| 编辑 | 打开表单修改该区块 |
| 复制 | 生成副本（标题加「 副本」），插在该区块之后 |
| 删除 | 只删这一个，带二次确认 |

### 区块卡片

保存后，区块出现在你选的区域里，卡片右上角有 **编辑** 与 **删除** 两个按钮 ——
不用回到编辑器列表也能改或删。

### 编辑表单

新增与编辑共用同一个表单，标题会相应显示「新增区块」或「编辑区块」。

| 字段 | 说明 |
| --- | --- |
| 区块标题 | 留空显示「自定义区块」 |
| 放置区域 | 通栏（两栏下方）／左栏底部／右栏底部 |
| 启用 | 关闭后不渲染，**也不接收数据** |
| 允许执行脚本 | 见下方「关于『允许执行脚本』」 |
| 数据回传 · 通道名 | 留空 = 不接收数据。会写进模型任务书 |
| 数据回传 · 渲染方式 | 内置表格渲染 ／ 仅派发事件（自己写脚本） |
| 数据回传 · 累积各轮 | 勾选后每轮一张表累积显示，否则只显示最新一轮 |
| 数据要求 | 自然语言描述你要什么数据，随指令发给模型 |
| 自定义配置 | 每行一条 `key=value`，脚本里用 `block.config` 读取 |
| HTML 源码 | 区块内容，不能为空 |

字段的完整语义与 HTML 写法见 **[区块格式规范](blocks.md)**。

## 数据存在哪

区块存于浏览器 `localStorage` 的 `page-blocks-v1` 键。**保存 / 删除 / 排序 / 复制
每一次操作都会立刻写入**，不存在「忘了保存」的情况。

完整的键清单与迁移方式见 [存储与迁移](../panel/storage.md)。

> ⚠️ **「导出 JSON」只包含区块**，不包含配置面板状态（自定义频段、自定义特殊需求、
> 首次配置都不在内）。搬迁地址时尤其容易踩到这一点。

### 什么时候区块会「看起来丢了」

区块不会自己消失。读不到通常是下面三种情况之一：

1. **换了 origin** —— 换了端口或 host。`127.0.0.1:3080` 与 `127.0.0.1:8080`
   是两份互相看不见的 `localStorage`。
2. **用了无痕 / 隐私窗口** —— 关窗即清空。
3. **清了浏览器数据**，或换了浏览器 / 用户配置。

前两种情况下数据其实还在原来的 origin 里，回去就能看到。要迁移，先在原地址
「导出 JSON」，在新地址「导入 JSON」。

## 关于「允许执行脚本」

新增区块**默认勾选**「允许执行脚本」，即默认允许交互。

- 通过 `innerHTML` 注入的 `<script>` 浏览器**不会执行**，页面是用「动态创建 script 元素」
  的方式显式执行的 —— 所以这是一项显式能力，不是偶然。
- **取消勾选后不会再次执行**；但**已经执行过**的脚本若注册了定时器或全局事件监听，
  这些副作用不会因取消勾选而自动解除，**需要刷新页面才彻底停止**。页面提示条如实写明了这一点。
