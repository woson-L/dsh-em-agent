# 安全说明

> **文档索引** › [参考](../README.md) › 安全说明

### 脚本执行模型

- 通过 `innerHTML` 插入的 `<script>` **浏览器本身就不会执行**，这是默认安全的来源，不依赖额外过滤
- 只有区块显式勾选**「允许执行脚本」**后，页面才会把 script 元素重建一遍使其运行
- 因此默认状态下，自定义区块只能是静态 HTML + CSS

### 勾选「允许执行脚本」意味着什么

该区块的脚本与页面**同源、同一全局作用域**，能力等同于页面自身代码：

- 可读写 `localStorage`（含其它区块配置、面板配置）
- 可通过 `dshRpc()` 调用 DSH 接口，包括创建会话、发送指令、取消任务
- 可访问页面上任何元素与变量

**请只粘贴你自己写的、或你完全信任的来源的 HTML。**

### 导入 JSON 的风险

导入的区块 JSON **可能带脚本**。导入前请先打开文件检查 `html` 与 `allowScripts` 字段。
建议先把导入的区块以 `allowScripts: false` 打开查看内容，确认后再考虑启用脚本。

### 模型输出的处理

内置渲染器处理模型回传数据时，**表头与单元格一律通过 `textContent` 写入**，不解析 HTML，
因此模型输出无法借数据通道注入标记或脚本。

但如果你在 `custom` 模式里自己用 `innerHTML` 渲染 `d.payload`，就绕过了这层保护，需自行转义。

### 凭据与路径

- 首次配置里的 CST 路径、MCP 地址存于浏览器 `localStorage`，**不写回源码文件**，也不发送到任何第三方
- 只有你在「数据要求」里写的文字会随任务指令进入 DSH 会话
- 公开分享区块 JSON 前，请检查里面是否含有你的本机路径等敏感信息

### 预览区的 id 冲突

编辑器的「实时预览」是区块 HTML 的第二份拷贝，预览打开期间其中的 `id` 会与真实区块重复。
关闭编辑器时预览内容会被清空。若脚本依赖 `getElementById`，注意不要在编辑态下误取预览里的元素。
