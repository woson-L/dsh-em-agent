## 设计定位（先读房间，再动手）

**Reading this as: 面向射频/天线工程师的 Operate 型工程控制台**，精密仪器语言，
落在一套自定义 CSS 设计系统上（单文件、离线、零依赖）。

这个定位决定了三件事：

1. **它不是落地页。** `design-taste-frontend` 在 §13 明确把 dashboard / 密集产品界面列为 out of scope，
   并要求"说清楚，然后只套用适用的部分"。所以本次**没有**套用它的 hero 规训、bento 网格、
   配图策略、marquee 等营销页规则；只取用了与界面类型无关的部分：字体层级、色彩克制、
   AI 套路清单（§9）、组件状态完整性、以及交付前的 Pre-Flight 检查。
2. **`impeccable` 取 Operate 模式。** 它对这个模式的判词是"可扫读性、一致性、原生预期、
   真实使用场景优先于表现力，品牌活在精确的细节里"——这正是本页面该走的路。
3. **不迁移技术栈。** `redesign-existing-projects` 的第一条纪律是"沿用既有技术栈，不迁移框架"。
   页面是单文件内联 CSS/JS、无构建步骤、无 npm 依赖，因此**不引入 React / Tailwind / 组件库 / Web 字体**，
   全部用原生 CSS 完成。

### 三个旋钮（按 Operate 面校准）

| 旋钮 | 取值 | 理由 |
|---|---|---|
| `DESIGN_VARIANCE` | **3** | 密集工具界面，对称与可预期优先于表现力 |
| `MOTION_INTENSITY` | **3** | 只保留 hover / active 反馈与一处入场，仿真控制台不该持续动画 |
| `VISUAL_DENSITY` | **6** | 数据密集但不到驾驶舱；保留卡片分组，不改成纯 1px 分隔线 |

## 布局

- **外壳栅格**：`--shell-max: 1480px` + `--shell-pad: 22px`，由令牌统一驱动，
  顶栏与主内容共用同一内缩量（此前的硬编码错位问题已根治）。
  1600px 视口下内容区实测 82..1517，全页一条竖向基准线。
- **两栏**：左 56% / 右 44%，`align-items: stretch` 使两栏始终等高；
  多余高度交给"可增长的子块"吸收（左栏末卡的操作日志、右栏首卡的事件流），
  因此两栏底边严格齐平，而不是靠留白凑。
- **纵向节奏**：统一 16px 卡距、18–20px 卡内边距。间距令牌尚未全量提取（见[样式令牌](tokens.md)），
  但取值集中在 10–18px 窄区间，疏密均匀。
- **折叠卡**：收起态收紧为单行、去掉悬空分隔线——原先那种"标题下方拉一条线、线下还留 18px 空白"
  的观感像渲染断掉，现在收起就是干净一行。

## 色彩

- **单一强调色**：靛蓝 `--primary`。绿/琥珀/红只承担语义（PASS / 阈值 / 失败），不做装饰。
  本轮把「启动仿真」从绿色实心改为强调色实心，页面不再有两个主操作色；红色只留给破坏性操作（取消）。
- **中性面三级**：`--bg → --surface-2 → --surface`，靠底色差 + 1px 描边建立层次，而不是堆阴影。
  阴影只有两档极轻投影（`--shadow-xs/sm`），首屏任务条用 `--shadow-md`。
- **阴影带背景色相**：所有阴影用 `rgba(19,28,43,…)`（冷蓝黑）而非纯黑，避免灰扑扑的脏感。
- **无纯黑纯白**：深色主题底色 `#080c13`、浅色文字 `#131c2b`，均非 `#000`/`#fff`。
- **对比度**：24 组前景/背景配对在构建期硬校验（正文 ≥4.5:1，非文本控件 ≥3:1），
  不通过直接构建失败。实测正文 17.09:1、辅助文字 6.99:1、最弱的禁用按钮 4.50:1。
- **极细颗粒层**：`body::after` 固定定位、`pointer-events: none`、不透明度 4.5%，
  用来打破纯数字平面的塑料感；`prefers-reduced-transparency` 下自动关闭。
  （注意：颗粒层是 `position: fixed`，整页截图只会在首屏绘制一次，截图里看不到不等于没生效。）

## 字体

- **不加载任何 Web 字体。** 单文件离线场景下，外部字体要么带来网络请求、要么带来体积。
  字体栈改为**优先使用本机已装的 Geist / Inter**，没有则回落系统 UI 字体——
  纯渐进增强，零请求零体积。等宽同理（Geist Mono → JetBrains Mono → Cascadia Mono）。
- **字号阶梯**：`--fs-micro 10.5 / xs 11.5 / sm 12.5 / base 13.5 / md 15 / lg 16.5 / xl 21`。
  主标题用 `--fs-lg`（16.5px），卡片标题用 `--fs-md`（15px），正文 13.5px——**层级差 1.5px 起**。
  （上一版主标题 15px 与卡片标题 14.5px 只差 0.5px，页头几乎没有锚点，本轮已纠正。）
- **数字排版**：所有数值走等宽 + `font-variant-numeric: tabular-nums`，
  增益/效率/PASS-FAIL 逐位对齐，扫读一列数字不需要横向追字。
- **断行控制**：标题 `text-wrap: balance`、正文 `text-wrap: pretty`，消除孤字与参差末行；
  辅助说明在宽屏下限制 `65ch` 上限。

## 组件

- **卡片**：统一 16px 圆角 + 1px 描边 + 同一套标题（15px/700 + 34px 蓝色渐变短下划线）。
- **形状语义**：**状态 = 圆胶囊，分类 = 4px 方徽标。** 这是本轮建立的规则，
  扫读时不读字就能分辨。此前区块列表里的「通栏 / 通道 stats / 累积」还是胶囊，
  与规则冲突，本轮已统一为方角。
- **表格**：表头统一 `--fs-xs` / 600 / `.03em` / `--text-sub`（原先汇总表用 10.5px/700/居中、
  示例表用 11.5px/600/左对齐，属两套语言，已归一）；默认只用横向分隔线，无竖线。
- **按钮**：primary（强调色实心）/ 描边次级 / err（破坏性）三档。
  **禁用态一律中性灰**——半透明的饱和红/绿会被读成"仍在发光的主操作"。
- **空状态**：KPI、汇总表、图表、区块列表都有专门空态。
  **本轮修正**：无数据时不再给占位符预涂语义色（原先「最差 S11」的「—」是琥珀、
  「最佳候选」的「—」是绿，等于对未知状态下达好/坏判断），出数才着色。

## 交互与响应式

- **动效克制**（`MOTION_INTENSITY 3`）：只保留 hover / active 反馈与一处入场，
  全部走 `transform` 与 `opacity`，不触碰布局属性。
- **缓动统一**：`--ease` / `--ease-out` / `--dur-fast` / `--dur-base` 四个令牌，
  本轮把 21 处硬编码时长全部改为引用令牌（上一版仅 1 处在用）。
- **无障碍**：键盘跳转入口（skip link）、`:focus-visible` 焦点环、`aria-label`、
  `role="separator"` + 方向键微调的高度拖拽条、`prefers-reduced-motion` 全局降级。
- **响应式**：1080px 断点两栏堆叠、520px 断点收紧内边距与按钮宽度；
  示例参考在 900px 以上转两栏（说明 + 表格），避免右侧大片空置。

## 已知取舍与未做的事

- **间距未全量令牌化**：全文仍有 12 个硬编码间距取值。当前节奏稳定，但缺少离散刻度，
  后续改动容易漂移。建议下一步抽 `--space-*`。
- **字号阶梯落地约七成**：仍有个别硬编码（如 `.pill` 的 12px）。偏差 ≤1.5px，视觉不可见。
- **事件流卡的空井**：为满足"两栏等高"的要求，右栏首卡以 `flex: 1 1 auto` 吸收剩余高度，
  空数据时会有约 267px 的空白。这是**默认状态**下等高布局的代价。
  用户可以向上拖动底部手柄把这块空白消掉 —— 一旦拖过，该卡与手柄会切到
  `flex: 0 0 <高度>`，不再参与拉伸，此时右栏会短于左栏（这是用户主动选择的结果）。
  双击手柄即回到默认的自动填满布局。见 [事件流高度（可拖拽）](../panel/sections.md)。
- **未引入图标库**：`design-taste-frontend` 要求用 Phosphor / HugeIcons 等图标库，
  但单文件离线场景无法引入依赖。图标全部以内联 data URI 提供（favicon、主题图标、箭头等，共 6 处），无外部图标库、无外部请求。
- **颗粒层强度**：4.5% 是"可感知但读不出噪点"的折中，可通过该层的 `opacity` 直接调整。
